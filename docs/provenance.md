## 이번 과제에서 한 변경

- 점검 엔진 7개 모듈을 재사용하고 기존 제품 전체, DB, 인증, 내부 문서 링크는 포함하지 않았다. 2026-10-28 사용자 요청으로 기존 공식 로고와 favicon을 원본 바이트 그대로 재사용하고 PwC 디자인 가이드의 웹 UI 토큰을 적용했다.
- 고정된 실제 감사인 정보를 가상 프로필로 교체했다. 사용자 지정 프로필은 이름·고유번호·주소·대표자를 검증한 뒤 매 점검에 적용한다. 프로필이 달라지면 결과 설명도 다시 계산한다.
- 모듈 import의 기존 제품 캐시 꼬리표와 원본의 회사 사례를 설명한 전체 줄 주석을 제거했다. 핵심 원문 보존·규칙·수동 확인 동작은 유지한다.
- 내부 운영실태보고기준 링크를 원문 직접 대조 안내로 교체했다. 외부 이력 자료는 연결하지 않으며 관련 항목을 수동 확인으로 남긴다.
- 압축 파일 20MiB, 항목 1,000개, 헤더에 선언된 해제 크기 합계 80MiB를 검사한다. ZIP 해제 중 실제 출력이 선언 크기를 초과하면 중단해, 거짓 크기 헤더가 제한을 우회하지 못하게 했다.
- 범위가 명확히 지원되는 코드일 때만 점검한다. 범위 밖·코드 미상은 `result: null`로 반환한다.
- 공개 체험 자료는 원본 테스트의 합성 DSD 생성 구조를 재사용해 가상 회사·감사인·인물·주소로 작성했다. 실제 고객 DSD·메일·이미지는 포함하지 않았다. 출처: `tests/checklist_rules.test.mjs`, 같은 기준 커밋.
