# DSD 원문 표시 수정

독립 앱은 robotic_web의 DSD DOM 렌더러만 가져오고 원문 전용 CSS를 빠뜨렸다. 일반 문단 여백과 표 자동 너비가 적용되어 원문 간격, 제목, 표 테두리와 열 비율이 무너졌다.

public/dsd-view.css에 원문 스타일을 분리하고 index.html에서 명시적으로 불러온다. 표의 COLGROUP 비율과 원문 너비, 병합 셀, 정렬을 유지한다. 넓은 표는 문서 패널 안에서만 좌우로 이동하며 모바일 페이지 전체는 넘치지 않는다. 검사 규칙·원문 데이터와 제출 보고서는 그대로다.

원본 checklist.html의 ck-shell에서 최종 적용되는 표 글꼴 12px, 셀 안쪽 여백 2px 4px, 줄 높이 18px도 동일하게 적용한다.

## 확인

- tests/dsd-rendering.browser.mjs: 수정 전 문단 위 여백 14px 때문에 실패했다. 수정 후 문단 여백 0, 공백·줄바꿈 유지, 바탕 글꼴, 표지 제목 28px, 고정 표 너비 600px, 열 비율 2:1, 표 테두리와 무테 구분, 셀 정렬·병합·쪽 구분과 원문 블록 연결을 확인하였다.
- 모바일 390px에서 원문 패널 322px 안에 원래 600px 표를 유지하고 가로 스크롤할 수 있다. 페이지 폭은 390px이다.
- 첨부 ZIP 28개 DSD 모두 58행을 표시하고 원문 표의 고정 배치와 테두리, 패널 안 가로 스크롤을 확인했다. 페이지 오류 0, 비우기 후 원문 DOM 제거를 확인했다. 고객 원문과 파일명은 이 기록에 포함하지 않는다.
- 기존 자동 시험 11/11 통과, 실패·건너뜀 0. 제출 Word/PDF와 캡처의 Git diff는 없다.

브라우저 시험은 로컬 서버 실행 후 NODE_PATH에 Playwright 설치 경로를 지정하고 node tests/dsd-rendering.browser.mjs로 실행한다. TEST_BASE_URL로 확인할 배포 주소를 지정할 수 있다.
