# 디자인 적용

2026-10-28 21시대 요청에 따라 PwC 디자인 가이드의 오렌지 색상, 여백, 글자 위계와 입력·버튼 스타일을 적용했다. 로고와 favicon은 넣지 않았다. 홈페이지는 감사인 기준 확인과 DSD 파일 선택 중심으로 구성했다. 브라우저 메모리 처리, 결과 탐색과 내보내기를 짧은 문장으로 설명한다.

최종 보고서는 요약과 문제 정의를 앞에 두고 최신 화면, 구현 구조, AI 문제 해결 사례3개, 실제28건 결과로 구성했다. 화면은 실제DSD-04 입력으로 재촬영했으며 회사명은 화면에서 가렸다. 기존 보안·회사 공식성·확인 주체 주기와 강의 연결표·제출 절차는 최종 문서에 포함하지 않았다.

최종 문체와 서식을 정리하였다. 본문은 평서형 문장으로 통일하고 문제 해결 사례는 연결된 문단으로 서술하였다. Word 기본 글꼴 테마가 지정 글꼴을 덮지 않도록 제거하여 제목Georgia·영문Arial·한글맑은고딕이 실제 출력에 적용되도록 하였다. 표의 수치 정렬과 문단 간격도 맞추었다. 프론트는 제목·설명을 간결하게 바꾸고 기본 감사인 기준을 접어 파일 선택이 먼저 보이도록 하였다.
