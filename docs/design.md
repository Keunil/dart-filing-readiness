# 개인 과제 디자인과 표시 기준

2026-10-28 추가 피드백으로 기존 공식 로고·favicon은 public/에서 제거했다. 흰 배경, 검정 본문, 회색 강조와 맑은 고딕/Georgia·바탕의 글자 위계를 사용한다. 기존 디자인 가이드에서 참고한 간격·가독성·포커스·반응형 원칙은 유지하되 회사의 공식 시각 정체성이나 승인을 주장하지 않는다.

첫 화면과 보고서 요약에 개인 프로토타입이며 삼일회계법인/PwC 공식 서비스나 승인 제품이 아니라는 안내를 넣었다. 회사 내부 인력 운영·조직의 역할을 단정하는 표현은 없애고 작성자의 경험에 한정했다.

오류 상태는 화면·CSV·XLSX에서 오류 후보로 표시한다. 값 fail과 규칙 번호 및 판정 조건은 바꾸지 않았다. 화면은 감사인 식별값(8자리), 설명은 DSD의 AUDIT_CIK 필드와의 비교임을 명시한다.

캡처 4개는 개인 안내와 중립 색상을 반영한 로컬 수정본에서 Codex 브라우저 자동화로 다시 만들었다. 작성자의 독립적인 수동 확인으로 쓰지 않는다.
