## R9-01 P3 원본 화면의 유효 표 글꼴과 행 간격 미이식

- 위치: public/dsd-view.css의.dv-table및셀스타일.
- 근거: 비교대상robotic_web e4001fa의checklist.html에는ck-shell클래스가있다. checklist.css후단의.ck-shell .dv-table {font-size:12px}, 셀padding:2px 4px와line-height:18px가실제로적용된다. 현재이식본은앞부분의기본값13.2px, padding:3px 4px 2px, line-height:1.6만가져왔다.
- 영향: 원본보다표문자와행높이가커지고같은열비율에서도줄바꿈·세로길이가달라진다. 핵심표복구는작동하지만원본과의표현정합이남는다.
- 해결조건: 이앱의원문표에12px/2px 4px/18px를적용하고브라우저시험에서실제computed값을확인한다. 제출보고서와캡처는갱신하지않는다.
- 부류점검: 다른후단오버라이드는핀·별도헤더카드·범위강조용이어서현재앱에이식할필요가없다. 머리칸회색은원본dsd-head와현재bg-disabled가같은#DFE3E6이다. 페이지구분선음수여백은원본래퍼용이므로현재0유지에문제없다.
