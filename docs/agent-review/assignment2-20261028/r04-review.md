- manifest의 모든 파일 SHA-256이 현재 디스크 바이트와 일치한다.
- 공개 제출ZIP은 최신Word와PDF 두 개이며 각각 최종 산출물과 바이트가 같다.
- ignored private 제출ZIP은 최신Word와원본DSD ZIP 두 개뿐이다. Word는 최종본 바이트와 같다. 내부 원본ZIP은 사용자 제공 업로드 원본과 바이트를 직접 대조해완전히 같음을확인했다. 내부DSD는28건이며CRC오류가없다.
