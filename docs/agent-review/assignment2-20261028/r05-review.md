## R5-01 P3 화면 오류 발견 자료를 불필요하게 한정함

- 위치: docs/development-report.html의5절 도입부, Word/PDF5쪽 첫 문단.
- 실제: “구현 후 실제 DSD를 실행하면서 발견한 화면 오류”라고 하여 기존 스크롤·모바일 오류의 발견 입력을 실제 DSD로 한정한다. 기존 개발 기록은 가상 체험과 UI 시험에서 관측한 과정도 포함한다.
- 기대: 발견 자료의 종류를 덧붙이지 않고 구현 과정의 오류 수정으로 표현한다.
- 해결 조건: “구현 과정에서 발견한 화면 오류를 다음과 같이 수정하였다.”로 수정하고 Word/PDF·manifest·두 제출 ZIP을 갱신한다. 면책이나 확인주체 설명을 복원할 필요는 없다.

## 확인 완료

- 요약과 문제를 먼저 제시하고 본문을 하였다/한다/이다의 평서형으로 정리했다. AI 문제해결3사례는 연결된 문단이며 필수 내용과수치를 유지했다.
- 최신6쪽PNG를 모두 열어 확인했다. 이미지4개·링크2개와최신학번이 있고 큰공백·잘림·겹침·표넘침은 발견하지 못했다. 로고없음과불필요한주기제거요청을유지한다.
- Word의테마글꼴속성이제거됐고 PDF에Georgia·Arial·맑은고딕서체가포함됐다.
- 공개첫화면은감사인설정이접힌상태이며 실제파일선택이먼저보인다. 최신캡처도이에대응한다.
- 대상커밋의공개ZIP두항목은대상Word·PDF바이트와정확히같으며CRC오류가없다.
- private제출ZIP의두파일구조와Git무시·미추적설정을확인했다. 원본ZIP바이트는앞선r04에서직접대조한그대로이며r06에서최종Word갱신과함께재확인한다.
