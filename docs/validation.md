- 실제 DSD 파일 선택과 파일 없는 합성 체험 경로가 같은 엔진으로 작동한다.

- 오류·확인 필요·수동 확인·통과·해당 없음을 유지하고 확인 체크를 자동 판정과 구분한다.
- 근거에서 원문 위치를 확인하고 CSV·XLSX를 내려받을 수 있다.
- DSD와 결과를 서버로 전송하거나 저장하는 앱 코드가 없다.
- 공개 웹 주소, 소스 저장소, 실제 화면 캡처와 AI 문제 해결 기록을 보고서에 포함한다.
